# Introduction to Software Engineering - Ex1

## Project Scope & Goal
Implementing a robust and runtime-efficient 3D volume projection algorithm in Python. 
The program projects a 3D volumetric data matrix (NRRD format) onto a specified 2D plane defined by 3 or 4 points (isosceles triangle or trapezoid), outputting a sequence of frames as an MP4 video based on coordinate entries from a CSV file.

## Requirements
- Python 3.x
- NumPy
- PyNRRD
- OpenCV
